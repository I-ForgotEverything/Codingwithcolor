# CodeWithColor

A colorful, Duolingo-inspired coding learning path built with Streamlit.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`.
4. Run `streamlit run app.py`.

## Customize
Edit the `LESSONS` list near the top of `app.py`. The total lesson count and progress bar update automatically.

The starting demo shows 2 completed lessons and a 2-day streak. Progress currently lasts for the browser session; permanent accounts and streaks need a database.
